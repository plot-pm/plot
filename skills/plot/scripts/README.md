# Helper Scripts

Scripts in `skills/plot/scripts/` that any model tier can use:

**Kind** says what a script holds. *launcher* resolves a bundle and `exec`s it, and decides nothing. *readings* collects facts and asks a bundle for the decision. *paired* duplicates a domain rule on purpose, and a corpus test compares the two. *decision* and *orchestration* are the kinds that still carry logic in shell. `scripts/check-decision-count.sh` counts every row whose Kind is not *launcher* — *readings* and *paired* included — and fails when a change raises the number. A row that moves to *launcher*, *readings* or *paired* names its evidence in *Replaced by*, and each named path must hold at HEAD: a `.mjs` bundle for the first two, which is built under `skills/plot/scripts/board/` or declared in `packages/board/build.mjs` with an entry source that exists, and a `rules/*.ts` export and a `*.corpus.test.ts` file for *paired*.

**To regenerate the "first operator-command script" ranking:** list every row whose *runs* is `once per operator command`, exclude `plot-host.sh`, `plot-dispatch.sh`, `plot-fleet-scan.sh`, `plot-reconcile-scan.sh` and `plot-worker-loop.sh` (each a plan of its own), then sort the rest by `./scripts/check-shell-lines.sh --per-file` largest first. The top of that list is the next script to become a JS entry.
