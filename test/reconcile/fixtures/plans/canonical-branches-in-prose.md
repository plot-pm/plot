# Plan whose prose illustrates the Branches section

> A plan that documents the plan format necessarily quotes it. Only the first
> `## Branches` heading is the real one.

## Status

- **Phase:** Approved
- **Type:** feature
- **Review:** pr
- **Impl:** own branches

## Branches

- `feature/real-one` — the only real branch
- `feature/real-two` — the other real branch

## Design

Plans that document the plan format quote a `## Branches` section as an example.
Those quoted headings must not contribute branches:

## Branches

- `feature/illustrative-not-real` — appears in prose, must be ignored
- `docs/also-not-real` — likewise

## Notes

Trailing prose mentioning `feature/mentioned-in-notes` must not leak either.
