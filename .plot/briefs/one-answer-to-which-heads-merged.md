### The decisions the plan settles — do not re-derive them

**Removal is the fix, not a side effect of a bigger change.** The issue
`git grep`'d `pr_merged_heads` and found it only in its own file, in
comments, and in the two `host.test.mjs` assertions — no script calls it.
`packages/board/plot-reap.sh`, which still calls `pr_merged_heads` at
`:330`, is **generated output, gitignored by
`packages/board/.gitignore:6`, and not the file you are editing** — it's
a stale pre-#1432 build artifact sitting in a working tree, not tracked
code. The tracked launcher, `skills/plot/scripts/plot-reap.sh`, is 13
lines and calls none of this file's functions. Do not "fix" the
gitignored artifact; it is regenerated by `pnpm build:board` and carries
no history worth preserving.

**No corpus test, because there is no pair once this is gone.** The plan
explicitly rejects adding one: "the issue accepts removal as done, and
removal ends the duplicate, so no corpus pair is needed." If you find
yourself writing a `packages/domain/corpus/*.test.ts` entry comparing the
shell and the domain for this question, stop — that is solving a problem
this slice closes by deletion.

**This lowers the shell-lines gate's measurement, which is the point, not
a side benefit.** `scripts/check-shell-lines.sh` counts non-comment,
non-blank lines under `skills/` and refuses growth against the merge
base. Removing ~13 lines of function body plus the dead comment block
only ever helps this gate — it gives headroom to a later slice in this
sprint ("Gate exit wording") that touches a different file under
`skills/` and must not raise the shipped total.
