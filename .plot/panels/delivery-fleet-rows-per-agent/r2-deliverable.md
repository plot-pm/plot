1. Slice 1 (`delivery-agent-roles`) is more than one PR. Plan text: "`AgentRole` widened to eight roles, a local reading per role, design and verify runs moved into Fleet rows, and the role chip as a domain fact and one component". The Approach names six distinct readings (registry entry, `fixer-attempts` mark, payload design/verify status, and "local state their runners write" for reviewer, approver, idea, brief), each with its own file and a "no reading, no row" fallback, plus a block move out of `AgentList.tsx` and a new component. The reviewer/approver/idea/brief readings are named only as "local state their runners write", with no file, so their size is unknown. Fix: split into (a) widen `AgentRole`, the chip, and loop/fixer readings, which unblocks plan 3's By slice; (b) design/verify move into Fleet; (c) reviewer/approver/idea/brief readings. Or state in Left to the Builder that the slice may stop at the readings that exist and name the rest as gaps.
2. Slice 2 (`delivery-fleet-agent-rows`) is also oversized. It bundles new groups, a new column set, Acting on links, Doing now (a new pulse git read for commits and subject), Waits on `ci` and `rate-limit` (two new readings), the daily-difference token fold over `slice-spend.jsonl`, the per-role time-left bar, the cached `Worker bound` read, Free collapse, the open-group change, and the tooltip move with a changed browser test. Fix: split at least the `Worker bound` cache plus time-left bar, and the Tokens fold, into their own slices (heading order already exists to carry them).

The Changelog's first line says the header counts working, blocked and free agents, and Approach says "the header counts are plan 1's section summary filled with the Fleet groups". Slice 3 builds "the existing switch strip ... and the header's output tokens today" only. Slice 2 builds groups but not the summary fill. No Done When line asserts the counts either. Fix: put the summary fill in slice 2 or 3 and add a Done When line for it.
