# Juror: cost

Position: amend

Lens: what the plan spends (CI, board, bumps, tests, mirrors), and whether it says so.

## Findings

1. **The "Board impact: none" claim is false, and the plan's own Notes repeat it.** The plan says "No parser reads the content of an Open Points line" (plan Changelog comment and `## Notes`). Read: `packages/domain/src/rules/plan-open-questions.ts:7-43` matches `### Open Questions` and `## Open Points` headings and returns the text of the first unchecked `- [ ]` item. `packages/board/src/server/board.ts:2535`, `:2787` and `:3511` call it. `packages/board/src/app/lib/agent-rows/draft-plan-row.tsx:64-67` renders `questions.first` as raw text in a truncated `<span>`. The template change puts `` `[question-…]` `` at the front of that text, so every Draft row on the board shows the backticks, the brackets and the identifier first, and truncation drops the question itself. The count chip is unchanged. Inferred (not run): the plan's own Open Point `` `[question-design-doc-citations]` Should `DESIGN-phases.md`… `` renders in that row as literal backticks. Amend: state the board impact, and either accept it or add a `planOpenQuestions` change that strips a leading `` `[kind-name]` `` (a domain change with a test, which moves the plan off pure `Type: docs`).

2. **A change to `skills/plot/templates/plan.md` runs every CI job, not a docs-only selection.** Read: `test/reconcile/ci-selection-jobs.test.mjs:128-133` names `skills/plot/templates/plan.md` as an untested path that "selects every job". Changes to the four `SKILL.md` files sit under `skills/` too. The plan says `Type: docs` and gives no CI cost; the true cost is a full CI run (e2e included) for a wording change. Not a defect, but the plan does not state it.

3. **The changeset carries five skill bumps, and the plan names none.** The plan says "one changeset". Files it changes ship in five skills: `plot` (template, `skills/plot/SKILL.md:12` version 2.29.0), `plot-deliver` (`:11` 1.14.1), `plot-approve` (`:13` 2.11.1), `plot-idea` (`:14` 2.6.0) and `story-tracking` (`:9` 2.1.0). `.plot/templates/plan.md` ships in no skill. `scripts/check-changeset-packages.sh` checks the names; the plan should list the five bumps and their level (patch for the citations, minor for the new story-tracking convention under this repo's semver rule).

4. **The user-facing refusal text keeps "(D10)", and a test pins it.** Read: `packages/board/src/server/approve.ts:332` and `packages/board/src/server/entry/approve.ts:1060` print "a person approves it (D10)"; `test/reconcile/approve.test.mjs:359` asserts `/D10/`. Code comments also cite codes: `packages/board/src/server/entry/gate.ts:438` (D14), `packages/board/src/server/entry/needs-design.ts:282` (D3), `packages/domain/src/rules/auto-deliver.ts:325` (decision D14). The plan scopes the rename to skill text, which keeps the cost low (no bundle, no test edit). But the operator who reads the refusal is the reader the Motivation names, and the plan does not say these stay. Amend: name them as out of scope, so a builder who follows the Motivation does not rename the message and break `approve.test.mjs:359`.

5. **Gates and tests that read the changed templates do not read the changed lines.** Read: `scripts/check-plan-headings.sh:25-27` checks only `## Branches`/`## Waves`. `packages/domain/test/sprint-member.test.ts:126-140` reads both plan templates for the `Sprint:` placeholder. `test/reconcile/parser.test.mjs:2592-2600` reads both for `agent:`. `test/reconcile/skills-say-slices.test.mjs:63-87` reads them for the slice vocabulary. `test/reconcile/storylint.test.mjs:95-104` uses a synthetic `STORY-template.md`. `packages/domain/src/rules/story-record.ts:109` tests only for `^## Open Points`. No parser reads a story Decision cell (no match for `## Decisions` or `⏸` in `packages/*/src`). No `CLAUDE.md` change, so no `AGENTS.md` mirror cost. Nothing found here.

6. **The convention misses the skill that writes most Open Points.** Read: `skills/challenge-the-plan/SKILL.md:247` turns each juror's unresolved finding into an Open Point; the plan does not change it. Plans written through a panel keep the old shape, so the templates carry the convention for a minority of Open Points. This is a scope cost: a second plan, or a sixth bump, later.

7. **Checked and true.** The four citations exist where the plan says: `skills/plot-approve/SKILL.md:128` (D10), `skills/plot-deliver/SKILL.md:580` (D14) and `:612` (D5, D14), `skills/plot-idea/SKILL.md` near `:281` (D3, already naming `DESIGN-phases.md`). The definitions are in `docs/stories/archived/plot-works-in-five-phases/STORY-plot-works-in-five-phases.md:79`, `:81`, `:86`, `:90`. The template placeholders are `skills/plot/templates/plan.md:36-38` and `.plot/templates/plan.md:56-58`, both `- [ ] ...`. The story template's Open Points use `⏸️`/`✅` bullets, not `- [ ]` (`skills/story-tracking/STORY-template.md:48-51`), so the plan's "bullets start with `[question-…]`" must sit after the emoji; the plan does not say where.
