The plan proposes `controllerInvocation(command)` as if no word-splitter or run-versus-read rule existed. Without a sentence naming this rule, slice 3 writes a second splitter beside the first, and the two drift on the next quoting case. `rules/start-command.ts:48` (`loopWord`) is a third matcher for "does this command run script N" and belongs in the same sentence.

The slice should either cover the shared reading or state that the other three stay defective and file them.
