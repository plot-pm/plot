The `loose` reason's `action` today is `create-plan` (`delivery-row-form.ts:228`), which is neither Release claim nor Delete branch, and the plan names no new `action` for it. RAN (sed, grep). **Change:** state the one target the test asserts. Either (a) the verb link resolves to a new `{ kind: 'menu', id }` target in `delivery-link-targets.ts` with a unit test there, and `action` stays only as the item the opened menu focuses; or (b) the verb link keeps `{ kind: 'act' }` and the plan drops "opens the row's `rowMenuOf` menu". In both cases name the `loose` reason's new `action`.
