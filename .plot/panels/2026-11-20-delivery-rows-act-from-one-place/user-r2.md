Without a stated item set per row kind, a builder can keep today's present/absent rule, give every surviving item `enabled: true`, and pass every unit test, and the person still sees Delete vanish on a claimed branch. READ the plan and spec; OPENED the four files cited. **Change:** in *⋯ column*, add: "Each row kind lists a fixed set of items, named per kind in its unit test; an item outside a kind's set is never listed, and an item inside it is listed disabled with its reason where it cannot run now. `looseActions` returns `{ enabled, reason }` for Release claim and Delete branch (reason words per refusal: claimed, carries work, open PR, unread claim), and `CleanUpMenu`'s `null` return goes."
