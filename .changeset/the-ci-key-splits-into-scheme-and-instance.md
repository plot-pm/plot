The `CI:` value is read as a scheme and an instance rather than one string, so a repository declaring `` CI: Jenkins at `jenkins-ci-ewz…` `` names the scheme `jenkins` where the whole prose value matched no caller's arm. The instance is extracted as a host — the first backticked span or bare token that looks like one, and empty where the prose names none — never as the remainder of the sentence. A `Jenkins instance` key overrides the prose, because it carries the job path no file in a repository states.
