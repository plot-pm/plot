The Delivery tab header shows one release card per release the Active sprints target, each with a five-segment bar over the sprints' plans, the number of distinct Owners, the release PR's state and the Approve release button. A release PR no sprint targets gets its own card, and a target with no release PR shows the button disabled with the reason. The release row leaves You and Work items, and the to-do list carries one "Approve release <version>" line that scrolls to its card.
