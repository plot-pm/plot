`refreshPrs` takes its PR-index store as a required parameter, so no board caller reaches the real file by omission. The fleet bridges its last PR-read failure as `prError` on `BridgedPulse`, and the board shows it in owned mode; a board that finds no index to serve reports that instead of a healthy reader. An owned refresh skips the supervisor, release-version, unmerged-branch and worker-question reads while the bridge `at` is unchanged.
