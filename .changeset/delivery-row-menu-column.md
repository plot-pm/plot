Every Delivery row carries one `⋯` in a fixed last column, at the same x in the You, Work items, Release delivery, Fleet and Tickets sections. A row with no action keeps an empty cell of the same width. Each row kind lists a fixed item set: an item that cannot run shows disabled with its reason, and the trigger itself never shows disabled. A slice row has one menu that holds its Start work, Slice this plan and branch items. A Tickets row's *Plan it ›* link is replaced by its `⋯`, which holds Create plan and Open issue.
