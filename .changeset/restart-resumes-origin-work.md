`restart` resumes a claimed slice whose work exists only on origin: where this machine holds no worktree for the branch, it cuts a desk under `Worktree root` at `origin/<branch>`, tracking it, and starts the agent there. The domain rule `originResume` decides, and refuses `no-worktree`, `origin-unreadable`, `not-claimed`, `no-work`, `held-by-agent`, `local-unpushed`, `pr-unanswerable` and `reached-review` before any desk is cut. The new manifest records the slice's `base` for a sprint plan, so the agent's PR targets the sprint branch.
