The six recursive greps that enforce the domain's boundaries now pass `-a`, so one NUL byte can no longer hide a whole file from them. `grep` classifies a file holding a NUL as binary and prints `binary file matches` instead of the matching lines — or, depending on the implementation, nothing at all — so a gate testing `[ -n "$hits" ]` reads an empty variable and reports clean. Measured 2026-09-01 on PR #610: `entities/finding.ts` builds a composite key as `${f.monitor}\0${f.branch}`, a deliberate and correct separator since a NUL occurs in neither half, and the actor-name gate failed that branch on two lines in `sample.ts` while four `WorkerMonitor` hits in `finding.ts` — one inside a `z.enum` — went unreported. The stakes were highest for the purity gate, where a domain file carrying a NUL could have imported `child_process` invisibly. A new `Gate greps read every file` step refuses any domain gate written without `-a`, so the blind spot cannot return through a seventh gate added in the old shape. `WorkerMonitor` joins the actor-name allowlist at the same time: it names the monitor whose subject is the process, beside `AgentMonitor` whose subject is the desk, which is the distinction CLAUDE.md draws rather than an exception to it — those four lines were always correct and are only now visible.
