A dispatch refused for a missing brief can ask for one. The optional `Brief command` config key names how to run an agent headless to write the brief, and its prompt asks for `/plot-implement <slug>` — whose step 4 already owns brief authorship, so the key adds no second writer. Absent or `none` means the capability is unavailable rather than an error: the gate still refuses, exactly as it does today.
