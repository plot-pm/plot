`build-jenkins.ts` gives the build port a Jenkins connector, so a repository declaring `CI: jenkins` reaches its builds through the port every reader uses rather than through a rendering special case. `runForSha` answers `unaskable` there, which is the transport's measured limit: `jenkins_build_map` reports one state per branch and names no commit.
