A release card names a release PR's version only where its root `package.json` version differs from the base branch's, so a release PR that bumps only `@plot-pm/board` no longer shows as the release already tagged. The PR pass re-asks an open PR whose checks read `none`, so a check or commit status that reports after the read reaches the index. The You row counts each release approval the to-do list counts, so both read the same number of blocked deliveries.
