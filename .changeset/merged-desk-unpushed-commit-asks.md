A merged desk that ends holding work and still holds an unpushed commit now asks a person instead of being left, because the ending rule reads the checkout's unpushed commits alongside its dirty paths. The reading is the reaper's merged-aware one: a commit a merged PR head holds, or one whose patch the default branch carries, counts as pushed, so a squash- or rebase-merged desk whose remote branch was pruned still leaves.
