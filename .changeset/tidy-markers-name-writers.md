A `PLOT-BLOCKED` marker names the branch and the session that wrote it, on its own line below the question. A marker written by one branch's worker into another's tree made a finished branch read as blocked, and the only way to tell was a person recognising a branch name that was not theirs. An agent with no session minted for it reports `undeclared` rather than being given a name nobody minted.
