The reconcile sweep reads the `active/` and `delivered/` indexes once per run rather than once per plan. `symlinked_from` answered *does a symlink in this index point at this plan?* by walking the whole directory and forking `readlink` and `sed` for every link it passed, and it was called twice per plan: over 297 plans and 368 links — measured 2026-09-18, 85 in `active` and 283 in `delivered`, all resolving — that is over 130,000 forks per sweep. Two further sites walked the same directories and never called the function — section 4's `active/` loop, which inlined the same `readlink | sed` pair, and section 5's dangling-link loop — so a fix phrased around the function would have left two walkers in place. All three now read one `ls -l` per directory, and the per-plan lookup forks nothing, including the `basename` at the top of the loop that cost a further 297 forks. Building an index is not the fix and stopping the forks is: a fork costs 38 ms on a loaded machine against 0.045 ms for a fork-free loop iteration, so an index built with one fork per link is still one fork per link — 368 today — and was measured at 22.7 s, against 0.081–0.529 s for `ls -l` over both directories. Measured on this estate the same day, a full sweep runs in 24 s where the walk it replaces exceeded 600 s, and the two reports are byte-identical across all 466 lines. Four properties a three-lens panel established are held by fixture tests, each a case where a wrong index still produces a byte-identical report on this estate: the `*.md` glob is a filter, so a link whose name does not end `.md` stays invisible and `docs/plans/active/` holding a `.omc` directory proves these directories are not curated; the first link wins, because three plans here carry two links each within `delivered/` and all three are delivered and therefore absent from drift; a drift row prints the link path in its `fix:` command rather than a boolean; and a dangling link keeps the raw target `readlink` printed, which no diff can catch where the estate has none. The fork count is asserted through a `PATH` shim rather than by timing — two replacements written while this was planned were slower than they looked, neither distinguishable from the fast shape by reading the diff, and a Done-when saying *faster* would have passed on both.
