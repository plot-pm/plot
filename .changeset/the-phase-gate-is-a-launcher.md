The phase gate decides in the domain: `plot-phase-gate.sh` shrinks from 264 lines to a launcher, and `phaseGateRefusal` and `holdRefusal` refuse an implementation commit while the plan is Draft or Design on `origin/<main>`, naming the phase as read. The gate runs as the fifth row of `plot-gates.sh`, so `hooks/hooks.json` registers one command instead of two, and a commit that carries a chained `git add` or `-am` is read through `effectivePaths`. A plan found nowhere allows silently, a plan found only locally allows and says to push it, and an unreadable `origin/<main>` allows and says to run `git fetch`. The slug matches by equality after the date prefix, so a slug with a regex character or one that prefixes a longer slug matches only itself.
