A continuation no longer resumes a role run's session or another branch's session. Each candidate handle — the stamped manifest's or the ending's, then the desk's transcripts newest first — passes the new domain rule `resumeHandleUsable`, and the continue command and `POST /api/continue` name the session: `resumes <handle>`, or `fresh session <handle>` with each rejected handle and its reason.
