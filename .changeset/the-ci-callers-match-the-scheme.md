Every arm that dispatches on the CI system compares the `CI` key's scheme, so a repository declaring `` CI: Jenkins at `jenkins-ci-ewz…` `` reaches the Jenkins arm and reports the ceiling it has — where all but the bare word read `basis: unknown`. `ci-limit` reports that scheme as its `connector` too: the domain filters readings by equality against a connector's bare system word, so a prose value was discarded before any caller saw it and a metered Jenkins read as metering nothing.
