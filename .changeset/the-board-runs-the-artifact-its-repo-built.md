`plot-board-probe.sh` reads a new `Board artifact` Plot Config key and resolves it before the plugin, so a repository that builds `board-server.mjs` runs the file it built. A relative value resolves against the main checkout, so a dispatch desk resolves the same file. A declared file that is missing answers `none` and does not fall back to the plugin. With no key, the order stays plugin, npm, checkout.
