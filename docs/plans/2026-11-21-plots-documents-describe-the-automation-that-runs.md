## Design

### Approach

**Two tiers.** The page makes one distinction visible before any table: Plot is usable without the fleet, and the fleet is a separate part with its own setup.

- **Tier one, Plot without a fleet.** Plans, approval, the board, and a person who implements or starts agents by hand. It needs the plugin and a `## Plot Config` section and nothing else. Every station has a by-hand path, and tier one uses only that path.
- **Tier two, the fleet.** A supervisor (fleetd), role agents and the merge loop, run by an operator. It has its own setup (the Worker command, the three Apps, a ruleset, an active sprint, a supervisor unit) and it needs an operator who runs it.
- **The bundle.** Inside tier two, only some steps have a key. Deliver, the fixer, the merge arm and the release tick have none while the supervisor runs, so they come as a bundle with the supervisor. The page says so plainly, and it names the only ways back to a person (the section "The two global levers" below). The page uses the words of the repository, "the fleet" and "the supervisor", and gives tier two no product name.
- **Where the by-hand path stays open.** Approval of a plan and the approval of a release stay with a person in both tiers.

**Where the page lives.** One new page, `docs/automation-spectrum.md`, linked from three places: the README section that now says "Why merging stays yours", the README "Configuration" section, and the dated note of the manifesto. `docs/` already holds the cross-cutting pages (`docs/review-status-rollout.md`, `docs/plot-in-the-pipeline.md`, `docs/definition-of-done.md`). A page under `skills/` would travel with one skill and not with the product. A table inside the README would grow the file that every visitor reads first (254 lines).

**Page outline.**

1. The rule in three sentences: each station has a by-hand mode and a fleet mode, a team adopts as many stations as it wants where a key exists, and approval and the release decision stay with a person.
2. `## Plot without a fleet`: the stations as a person runs them, and what the plugin needs.
3. `## The fleet`: what an operator adds, and the station table below, one row per station and one line per row. The two global levers follow the table.
4. Where a setting lives, in precedence order: the machine-local file `.plot/state/fleet-controls.json` (the board's switches), then `## Plot Config`, then the code default; the unit flag `--start-agents`; and the environment overrides `PLOT_WORKER_BOUND`, `PLOT_CORRECTION_BUDGET` and `PLOT_CHECKS_WAIT_SECONDS`. `Auto-dispatch`, `Auto-review`, `Auto-verify`, `Auto-design`, `Parallel agents` and `Machine override` read the file first and the config second (`fleet-settings-store.ts:212-222`). The file is gitignored (`.gitignore:30`), so what Plot's own repository sets has two parts: the committed key and a machine-local file that no checkout shows.
5. One line for each default on which readers disagree. `Checks wait` is 1800 seconds in the worker loop (`packages/fleet/src/server/entry/worker-loop.ts:2811`) and 3600 seconds in fleetd (`packages/fleet/src/shared/auto-merge.ts:383`). Plot's own repository sets 3600 (`CLAUDE.md:19`).

**Two global levers** sit beside the rows, and both belong on the page.

- **Scope.** Stations 6, 8 and 12 act only on what the one active sprint names (`packages/domain/src/rules/sprint-scope.ts:9-14`: no active sprint, two active sprints and a sprint with no unstruck item each answer "none", and nothing merges). Station 7 no longer reads the sprint scope. A person moves the scope with a `sprint: scope change` commit (`DESIGN-delivery-loop.md:21`, `:170`).
- **Back to a person.** `/plot-fleet --stop` stops the agents and unloads the supervisor (`skills/plot-fleet/SKILL.md:44`). Removing `--start-agents` from the unit line (`skills/plot/units/README.md:184`) stops the supervisor's own agent starts: free agents, fresh sessions, the unblocker and the main-repair start (`registryd-main.ts:4028`, `:4113`, `:4167`). While fleetd runs, only the keys and the scope in the table stop those passes. This is the bundle that tier two comes as.
