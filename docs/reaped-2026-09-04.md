## Restoring one

```
git push origin <sha>:refs/heads/<branch>
```

The SHA is the authority. A deleted ref is not undoable through the host, which is why the local backups were written before the deletion rather than after.

## What decided it

The host, never ancestry. Squash-merge leaves a merged branch permanently ahead of main, so `git merge-base --is-ancestor` cannot answer *did this land* — `mergedAt` can. Here every answer was the same: never merged, and closed on purpose.
